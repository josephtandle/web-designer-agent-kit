# Layout Atlas: 12 Composition Archetypes & Responsive Patterns

The Layout Atlas provides 12 foundational UI composition archetypes for Mastermind and All Sorted participant websites. Each layout is designed for distinct content hierarchy, mobile responsiveness, and high conversion clarity.

---

## 1. Editorial Split

### Structure & Purpose
Designed for executive consulting, advisory services, and strategic B2B offers. Features a high-impact headline and value summary on the left, paired with an executive commitment card or primary offer breakdown on the right.

### Layout Ratios
- **Desktop (1440px):** 2-column grid (`55% / 45%` or `1fr 1fr`), 48px grid gap, 96px vertical section padding.
- **Tablet (768px):** 2-column stack (`1fr 1fr`), 32px grid gap, 64px vertical padding.
- **Mobile (320px-390px):** Single-column vertical stack (`100%`), 24px gap, 40px vertical padding. Value card stacks below primary CTA group.

### Typography & Spacing
- Headings: Serif display (Georgia or Fraunces), 2.5rem to 3.25rem on desktop, 1.85rem on mobile.
- Body: Neutral sans-serif, 1.05rem with 1.6 line-height.

---

## 2. Portrait Expert

### Structure & Purpose
Designed for solo founders, independent practitioners, coaches, and keynotes. Centers authority around a single high-resolution portrait photograph, biography, methodology highlights, and consultation booking block.

### Layout Ratios
- **Desktop (1440px):** Asymmetric 2-column (`360px portrait / 1fr content`), 64px gap.
- **Mobile (320px):** Single column. Portrait photo scales to 100% container width (max 280px height) with rounded corners above bio text.

---

## 3. Masonry Gallery

### Structure & Purpose
Designed for photographers, visual designers, architects, and product creators. Showcases portfolio artifacts using varied aspect ratios.

### Layout Ratios
- **Desktop (1440px):** 3-column asymmetric grid (`1fr 1fr 1fr`) with offset item heights (e.g. 4:3, 1:1, 16:9).
- **Mobile (320px):** Single column stack, 16px gap, preserving aspect ratios with native image loading.

---

## 4. Case Study

### Structure & Purpose
Designed for agency deliverables, technical implementations, and client transformation stories. Structured around Problem, Solution, Quantifiable Outcomes, and Verifiable Client Quotes.

### Layout Ratios
- **Desktop (1440px):** 3-part vertical flow: Full-width problem header -> 2-column solution stack -> 3-metric outcome bar.
- **Mobile (320px):** Stacked single column with outcome metrics rendered as vertical stat cards.

---

## 5. Product Demo

### Structure & Purpose
Designed for SaaS tools, digital products, and interactive applications. Features a centered headline, primary demo canvas or console interface, and feature callouts.

### Layout Ratios
- **Desktop (1440px):** Centered max 1140px container, full-width interactive frame, 3-column feature grid below.
- **Mobile (320px):** Stacked features with scrollable code/demo preview container.

---

## 6. Course Curriculum

### Structure & Purpose
Designed for educators, workshop leaders, and digital academies. Displays module sequences, lesson breakdowns, estimated durations, and enrollment cards.

### Layout Ratios
- **Desktop (1440px):** 2-column layout (`65% curriculum accordion / 35% sticky enrollment card`).
- **Mobile (320px):** Single column stack. Enrollment card sits below module list or pinned at bottom screen edge.

---

## 7. Event Timeline

### Structure & Purpose
Designed for single-day summits, multi-day retreats, and virtual masterclasses. Features chronological agenda items, speaker assignments, and track badges.

### Layout Ratios
- **Desktop (1440px):** Vertical line timeline with left-aligned timestamps (120px) and right-aligned session cards (`1fr`).
- **Mobile (320px):** Timestamp shifts above session card title with left accent border line.

---

## 8. Hospitality Image-Led

### Structure & Purpose
Designed for venues, boutique stays, event spaces, and retreat centers. Uses full-width hero imagery and atmospheric photo grids.

### Layout Ratios
- **Desktop (1440px):** Full-bleed hero image container (80vh min height) with overlay glass panel.
- **Mobile (320px):** Fixed height hero container (60vh) with high contrast text container below image.

---

## 9. Product Purchase

### Structure & Purpose
Designed for single products, membership tiers, or digital downloads. Highlights pricing options, included features, guarantee terms, and instant checkout CTAs.

### Layout Ratios
- **Desktop (1440px):** 3-column comparative pricing grid or single centered conversion card (`max 540px`).
- **Mobile (320px):** Single column pricing stack with recommended tier highlighted first.

---

## 10. Publication Index

### Structure & Purpose
Designed for writers, research institutes, and newsletter publishers. Features article excerpts, metadata badges, author tags, and subscription inputs.

### Layout Ratios
- **Desktop (1440px):** 2-column editorial list with left featured article (`60%`) and right recent index (`40%`).
- **Mobile (320px):** Single vertical article stream sorted chronologically.

---

## 11. Community Hub

### Structure & Purpose
Designed for memberships, alumni groups, and founder networks. Displays member directory cards, active forum threads, and event schedules.

### Layout Ratios
- **Desktop (1440px):** 3-column grid (`25% navigation / 50% activity feed / 25% sidebar widgets`).
- **Mobile (320px):** Tabbed interface or single vertical stream with collapsible sidebar filters.

---

## 12. Single-CTA Campaign

### Structure & Purpose
Designed for waitlists, book pre-orders, lead magnet downloads, and high-urgency announcements. Focuses 100% of reader attention on a single action form.

### Layout Ratios
- **Desktop (1440px):** Centered single column (`max 680px width`), generous vertical whitespace, zero header navigation distractions.
- **Mobile (320px):** 100% width padded container with touch-optimized input fields (44px min height).
