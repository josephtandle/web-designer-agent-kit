Use the Web Designer agent to clean the visible prose in my website.

Target File: absolute path to index.html

Edit a safe copy of visible prose. Rephrasing is allowed when meaning, facts, evidence, and qualifications remain intact. Preserve exact quotations, technical and product names, dates, prices, legal text, citations, destinations, and SEO unless I explicitly authorize a change. Do not modify markup, attributes, classes, scripts, or CSS as a side effect.

Show representative before/after examples and reasons, then compare protected facts and qualifications. Remove em dashes from newly rewritten prose except inside exact quotations. Check mobile wrapping only if it is actually rendered, and report anything not observed.
